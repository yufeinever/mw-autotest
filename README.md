# mw-autotest

执行配置支持自动录像，默认960×540、30帧/秒、目标600kbps、默认上限600秒（可设置10～1800秒，最长30分钟），无声音。达到上限只结束录像，用例继续执行；报告可播放或下载MP4。仅录MobileWork页面，原生系统窗口不包含。`npm ci` 安装ffmpeg-static编码器；若跳过了安装脚本，执行 `npm run recording:setup`。可用标准HTTPS_PROXY配置下载代理。便携打包显式带入编码器和上游许可证。录像失败独立显示，不改变用例断言。

MobileWork 客户端自动化测试平台，包含本地控制台、功能用例与权限行为观察脚本，使用 CDP + Playwright 或客户端本地接口。

脚本列表可切换“功能用例 / 权限管控”，勾选、范围及全部执行只作用于当前分类。权限管控登记42个场景，24个提供执行入口、18个待条件；依据需求4.1，暂不覆盖4.2。每条由产品正常创建Session，在首次模型请求发出前按真实任务目录准备对应材料，随后观察实际工具、问询/拒绝、文件结果和后续是否继续；当前权限卡固定拒绝，不使用全局自动授权。未触发、需求冲突及证据不足记“已观察·待复核”，通过仅代表本次实际触发分支，不等于完整规范验收。入口已实现也不表示全部实机验收，详见[重设计v0.0.2](测试用例与脚本/权限问询4.1用例设计-v0.0.2.md)及[版本迭代说明](版本迭代说明.md)。

## 启动

使用 Windows 和 Node.js 22，在项目目录运行 `npm ci`，然后双击 `启动测试平台.cmd` 或执行 `npm start`。默认地址为 http://127.0.0.1:18888 ，端口冲突时明确报错，不自动换端口。

MobileWork 客户端、模型与 Skills 需要另行配置。配置说明见 [打包与迁移说明](打包与迁移说明.md) 和 [控制台说明](local-console/README.md)。

客户端连接统一使用 `local-console/client-connection.mjs`，仅将唯一主页面及其子框架交给Playwright初始化，避免内置浏览器空白宿主窗口拖住连接；不会关闭其他窗口。连接及前条页面交接均通过后才继续队列，失败时点击“检查连接 / 重新连接”重新核对。未增加脚本整体超时。后端升级需在队列处理完毕后重启；旧版重启会把未完成任务标为中断，不自动重跑。

# 首条用例一键执行

双击本目录的 `一键执行-首条用例.cmd`，或在项目目录执行 `node scripts/run-client-case001.mjs`。

前置条件：Node.js 与项目依赖可用；MobileWork 已登录，主界面 CDP 9223 可连接；没有未发送草稿或正在执行的当前任务。脚本不会自动重启客户端或更改构建配置。

每次运行创建独立证据目录，截图命名为 `1016-2215-03-日程管理自动填充.png`，时间取实际北京时间。步骤序号避免同一分钟内重复覆盖。相邻 JSON 保存页面状态，执行报告链接截图。

完整流程：连接与预检 → 新建任务 → 点击日常办公/日程管理 → 自动填充断言 → 发送 → 回答已知提问 → 核验白名单后允许一次日历规则读取 → 等待执行成功 → 输出内容结构断言 → 生成报告。

已知回答为“先给通用安排”“先做通用模板”“周五正常工作”，不代表用户真实日程。只有已核验哈希的技能脚本及本年度 export-rules-template 命令可以自动允许一次。新的问题、权限请求或技能变化标为阻塞，保留现场。

输出包含执行报告、结构化结果、环境信息、截图及页面状态。完成条件同时检查本次会话、执行成功状态及停止按钮；内容断言检查日程时间段和优先级，不要求模型逐字复现之前回答。

额外允许一次的已观察权限分支：任务读取 cli.md 时，访问 `C:\Users\86150\.mobilework\skills\workday-calendar\references\*`。仅限该明确路径，不开启完全访问权限。

只检查连接而不发任务：`node scripts/run-client-case001.mjs --check`。
续跑当前已知会话：`node scripts/run-client-case001.mjs --resume=ses_实际会话ID`。必须与当前页面的会话一致；续跑只验证后半段，报告标为 RESUMED，不把它计作完整用例 PASS。原阻塞报告保留。
端口可用 MW_CDP_PORT 指定，最长等待默认 10 分钟，可用 MW_CASE_TIMEOUT_MS 调整。退出码 0=通过/预检成功，1=失败，2=阻塞。

执行锁防止同一脚本并发。异常退出遗留锁时，先确认进程与会话状态，再移除 `runs/.client-case001.lock`。超时不会中止任务，测试会话和产物均保留。

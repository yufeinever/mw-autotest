# MW-CLIENT-002：会议纪要

来源：v1.8-1014 工作簿，第二张工作表“测试案例（客户端-多端兼容）”，第3行。

入口：控制台“会议纪要 · 第二条用例”，或双击“一键执行-第二条用例.cmd”。只读预检：`node scripts/run-client-case002.mjs --check`。

步骤：新建任务 → 日常办公 → 会议纪要 → 核对真实自动填充的 meeting-and-brief 技能与提示词 → 追加脚本内嵌会议文字（原用例允许二次编辑）→ 发送 → 从 session 核实完整文字确实发送 → 根据配置逐次处理弹窗 → 验证任务完成和最终助手回复。

材料固定在 `scripts/case002-meeting-data.mjs` 的 `meetingText` 常量中，依据[济宁市统计局2025年第2次局长办公会会议纪要](https://www.jining.gov.cn/art/2025/2/7/art_36041_2901232.html?xxgkhide=1)整理为摘要，非逐字转载。会议于2025年2月6日召开，2025年2月7日公开。运行时直接追加文字到真实输入框，不读附件、不加载外部材料文件、不下载网页。旧虚构材料保留在 `scripts/fixtures/case002-synthetic-meeting.mjs` 用于回归。

默认第一项、允许一次；控制台可覆盖选项/审批策略及模型。每次弹窗处理前等待1秒。当前页面有任务、弹窗或未发送草稿时保留现场，不重启或中断客户端。不使用全局执行锁；并行运行采用独立报告和会话，遇到同一页面资源竞争时如实记录。

内容断言：真实会议日期、议题、主持人与出席/列席人员、原则同意方案的决议、四个工作组及构成和包保范围、调查问卷与调研报告、综合科的明确分工。公开纪要未给出具体截止日期，必须标注未明确，不得补造日期或相对期限。断言只读取本 session 的最后一条无工具调用的助手回复，不匹配用户输入或页面其他会话。索要原始材料、泛化模板或任务状态成功本身不能算内容通过。

追加材料用真实文字输入，不按普通 Enter 创建换行（该键会发送任务）；保留自动填充技能和提示词，并核对材料完整。回归入口：`node --test scripts/case002-meeting.test.mjs`。

如果 CDP 截图超时，通过客户端自身的窗口接口切换并还原最大化状态，确认视口尺寸恢复后重试一次；不刷新页面、不发送额外消息。报告记录重试，重绘前后页面状态均保留，截图失败仍如实报告。

保存：配置快照、客户端版本、实际发送的文字、公开来源信息、中文步骤截图、断言报告、最终助手回复及脱敏 session JSON。落盘文字仅为执行证据，不作为输入文件读取。截图与目录沿用首条命名约定。缺少环境或超时记为阻塞，内容不符记为失败；不覆盖历史报告。

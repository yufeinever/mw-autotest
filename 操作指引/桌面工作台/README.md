## 脚本使用方式

1. 先按模块查操作编号，明确目标ID/名称、输入、入口、等待结果和收尾，再调用文中列出的现有共用实现。各文件是操作约定与代码导航，不是另一套独立执行器。
2. 操作在现有runner的 `context` 中进行：使用其 `page`、`control`、`resources`、`checkpointResources`、`capture`。连接复用 `local-console/client-connection.mjs`，不得另建页面、绕开18888调度或重复实现同一控件。
3. 新建前登记原集合和本轮唯一名称；创建后登记真实ID。修改、删除、停止及弹框关闭均限定本轮目标；业务断言由用例补充。正常、异常与强停共用现有恢复能力。
4. 等待实际列表、表单、请求结果或模型终态；不以固定睡眠、路由变化或模型自述替代完成。原生目录框用CDP确认PID，再由Python/Win32控件接口填写、回读及确认/取消；不用Computer Use。
5. 先区分“关闭面板/收起列表”“移除引用/注册”“删除任务/实体/文件”。当前没有对应入口时记录实际差异，不用删除代替关闭。

## 维护与证据

本系列依据原表、项目共用源码和安装版入口整理，不表示每项已实机通过。每份文件列出实现位置与相关用例；缺少通用函数的操作，列出现有steps位置或待接入状态，后续提取到相应 `mobilework-*.mjs` 后统一调用，不复制整段业务流程。

本文中的版本号是操作参考基线，不代表当前安装版本；用例接入及验证进度以[覆盖清单](../../测试用例与脚本/客户端多端兼容-覆盖清单.md)为准，不能根据本系列的操作条目推定已实现或已通过。

操作修改时，在本周需求及版本说明记录受影响编号和实际验证；执行结果仍写覆盖清单及 `runs/`，不在此覆盖历史结论。每次开发后最多测试5个用例，除非用户明确扩大。
